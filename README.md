ENJOY CREATOR ACADEMY — Brand New Website

Files are intentionally kept in one root folder. Every HTML file contains its own inline CSS and JavaScript; there are no separate .css or .js files.

Pages: index.html, course.html, portal.html, privacy.html, refund.html, terms.html

Open index.html to preview locally. For deployment, upload all files together to the same public web root. The Learning Portal button opens the configured Google Drive folder. Course enrollment uses the supplied Razorpay link.

Note: This is a static website. Google Drive permissions, payment confirmation, and course enrollment automation are managed by the respective services and are not implemented by this front-end.
